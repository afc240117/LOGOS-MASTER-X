# ETAPA 01AI — GABARITO ORIGINAL APROVADO

Referência usada: imagem original 1536x1024 aprovada pelo usuário.

O que foi feito:
- não usei a imagem cortada anterior;
- recortei DIRETAMENTE da referência original apenas a área central da Home;
- recorte original: x=220..1536, y=76..1024;
- resultado lógico: 1316x948;
- versão HD gerada: 2632x1896;
- sidebar esquerda continua HTML funcional;
- topbar continua HTML funcional;
- corpo central é a própria referência oficial;
- width 100%, height auto, object-fit contain;
- sem translateX;
- sem cover;
- sem crop por CSS;
- sem edição interna dos painéis da direita.

Como testar:
1. Substitua os arquivos.
2. Reinicie o servidor.
3. Abra em 100% de zoom.
4. Ctrl+F5.
5. Confira especialmente a borda direita e a junção com a sidebar esquerda.
