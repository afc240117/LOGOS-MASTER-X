# LOGOS MASTER X 3.7.7 — Splash, ícone fixo e temas

Alterações desta entrega:
- Splash inicial substituído pela arte oficial enviada pelo usuário.
- Barra de progresso real sobreposta ao contorno da barra existente na arte, abaixo dos quatro ícones centrais.
- Ícone do aplicativo fixado na arte oficial enviada; removida a seleção de ícones na tela Aparência.
- Manifesto PWA unificado em `manifest.webmanifest` com ícones fixos 192/512.
- Tema principal Clássico preservado como padrão no PC.
- Tema móvel Pro definido como padrão no celular/Android.
- Segunda opção Clean criada para PC e celular, com base escura, ciano suave e acabamento leve, sem substituir o Clássico.
- Opções antigas Moderno/Modernox são migradas para Clean; `auto` mobile migra para Pro.
- Versão atualizada para 3.7.7.

Segurança do pacote:
- `.env` não está incluído.
- histórico `.git` não será incluído no ZIP de entrega.
- `.env.example` permanece apenas como modelo sem segredos.
