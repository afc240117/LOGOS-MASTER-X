# O que subir no GitHub

Suba **todo o conteúdo desta pasta LOGOS-MASTER-X** para um único repositório.

Não suba:
- `.env`
- `.venv/`
- `node_modules/`
- `__pycache__/`
- arquivos de build temporários

Sugestão de nome do repositório:
`LOGOS-MASTER-X`

Depois da primeira subida, este repositório passa a ser a fonte oficial.
