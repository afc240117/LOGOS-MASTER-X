# LOGOS MASTER X 3.3 — PRONTO PARA USO

## Fluxo recomendado
1. AI HUB: deixe `Automático`.
2. Studio: escolha Sermão / Estudo / Esboço / Exegese / Aula / Devocional / Série.
3. Preencha texto, objetivo, tempo, culto, público e intensidade K7.
4. Clique `Gerar / Executar`.
5. Use `Abrir no Editor` para revisar.
6. Exporte em TXT, Markdown, Word ou PDF.
7. Use `Salvar projeto` e `Histórico` para recuperar materiais.
8. Púlpito usa automaticamente o texto atual do Editor.

## Bíblia
A Bíblia local é importável por JSON/CSV/TXT. Nenhuma tradução protegida por direitos autorais é embutida automaticamente.

## IA
O sistema usa Gemini, Groq, OpenRouter, Hugging Face e OpenAI conforme as chaves do Render.
Modo `Automático` faz fallback entre provedores.

## Segurança
Nunca coloque API keys em arquivos do projeto.
