# LOGOS MASTER 8.1 — Prompts Profundos

Esta revisão substitui prompts superficiais por uma arquitetura de prompt em camadas:

1. Prompt Mestre Integral
2. DNA K7 Master
3. Prompt específico do módulo
4. Perfil de duração
5. Perfil de culto
6. Intensidade K7
7. Quality Gate

Os textos estão em `/prompts/` e também são embutidos em
`app/web/static/prompt-library.js`, para poderem ser usados mesmo quando
o projeto é aberto diretamente como arquivo no Android (`file://`).

O DNA K7 é estrutural: base em Lamentações 5:21-22, restauração, progressão,
aplicação congregacional, clímax e apelo. Não há glossolalia e não há cópia
de identidade vocal específica.
