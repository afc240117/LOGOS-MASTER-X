# Módulos funcionais

- Laboratório K7: importa TXT/MD, análise estatística local, salva transcrição, cria prompt para análise profunda.
- DNA Pentecostal: editar/salvar/restaurar perfil K7 e aplicar aos geradores.
- Prompt Mestre: editar/salvar/restaurar/copiar.
- Pesquisa Bíblica: plano/prompt local ou geração via servidor.
- Sermão, Estudo, EBD, Esboço, IA Pregador: modo local + ChatGPT ou servidor/IA.
- Editor: salvar/carregar/copiar.
- Biblioteca/Backup: salvar, excluir, exportar/importar JSON.
- Modo Púlpito: cronômetro + leitura em letras grandes.
- Configurações: detectar/alterar backend.
